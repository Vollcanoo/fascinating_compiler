# 优化实现边界

本项目的性能提升全部来自静态程序分析和编译器代码变换。编译期不解释执行、不 JIT 执行
ToyC 程序，也不会预先算出 `main()` 的返回值后只生成一条返回常数的指令。

常量求值只在**所有操作数都已被证明为常量**时进行，适用范围限于 `const` 初始化、全局静态
初始化，以及数据流分析确定为常量的表达式。函数调用、循环和有副作用的操作不会通过执行
程序来求值；全局变量的读写在任何可能被观察到的位置都会保留。

## 已实现的优化

### 过程内（`lib/backend/optimize.ml`）

- 局部常量传播、复制传播、常量折叠（按 int32 语义，与目标机溢出行为一致）；
- 代数化简与强度削弱（`x*2^k → x<<k`、`x+x → x<<1`、恒等式与恒真/恒假比较等）；
- 局部公共子表达式消除，以及基于可用表达式数据流的全局公共子表达式消除；
- 带可达性的控制流敏感常量传播：条件为常量的分支只沿实际可达的一侧传播，
  另一侧连同其代码一起删除；
- 死定义删除（基于活跃变量分析）、死全局存储删除、不可达代码与无用标号删除；
- 赋值临时量折叠：`t = expr; x = t` 合并为 `x = expr`；
- 循环不变量外提（含在循环内不被写、且循环内无调用时的全局读）；
- 循环旋转：把顶测循环改写为底测循环，消去每次迭代的无条件回跳；
- 循环内立即数物化：把后端无法编码进指令、必须用 `li` 装载的立即数提升为临时量，
  再由循环不变量外提移出循环。

### 过程间

- 小函数内联（无调用、无回边、代价 ≤ 40 条指令的非 `main` 函数）；
- 尾递归改写为循环；
- 从 `main` 不可达的函数删除。

### 后端（`lib/backend/regalloc.ml`、`lib/backend/codegen.ml`）

- 基于指令级控制流图的活跃变量分析与图着色寄存器分配；
- 按循环深度加权的溢出代价，内层循环中的值优先保留在寄存器中；
- 寄存器合并偏好：入口参数、返回值、调用实参与调用结果尽量直接落在 ABI 规定的
  寄存器上，从而消去调用点周围的 `mv`；
- 调用者保存寄存器（`a0`–`a7`、`t3`–`t5`）只分配给不跨调用存活的值；`a` 寄存器还要求
  该值在每个调用点都出现在同一实参位置，避免实参装载互相覆盖；
- 栈帧按需建立：不溢出、不使用被调用者保存寄存器的叶子函数完全不建栈帧；
  只有存在溢出槽时才建立帧指针 `s0`；
- 指令选择：立即数直接进指令（`addi`/`slti`/`slli`）、2 的幂乘除模转移位、
  比较与条件分支融合（`slt` + `beqz` + `j` 三条合为一条 `blt`/`bge`）、
  尾调用后直接返回；
- 汇编级窥孔：消除互逆的 `mv`、`sw`/`lw` 同槽往返。

## 测试要求

回归测试必须覆盖带函数调用和全局副作用的程序，并确认 `-opt` 的输出仍然保留必要的运行时
存储与读取，不会退化成 `main` 直接返回预计算的常数。每个回归程序都在 `-O0` 和 `-opt`
两种模式下执行，结果与独立的 AST 参考解释器比对。

`test/regress/` 下的 RV32IM 模拟器与参考解释器只在编译完成后的回归与基准测试中使用，
不会被生产编译器链接或调用。生产入口固定为：

```text
源码 -> 语义检查 -> IR -> 静态优化 -> 寄存器分配 -> RISC-V 汇编
```
